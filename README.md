# IT Access Governance & Compliance Lab

A simulated educational project designed to practice the core responsibilities of an IT Governance, Risk & Compliance student role.

## What it demonstrates
- User access certification and review
- Privileged-access review concepts
- Terminated-account reconciliation
- Compliance activity tracking
- Exception management and follow-up
- IT risk register maintenance
- Control design / testing documentation
- Process documentation and continuous improvement
- Python-based access-review analytics
- Excel dashboarding and evidence tracking

## Project structure
- `Cameco_IT_Access_Governance_Compliance_Lab.xlsx` — governance workbook and dashboard
- `data/access_reviews.csv` — simulated access-review data
- `src/access_review_analyzer.py` — flags high/medium-risk access issues
- `reports/` — generated findings and summary
- `docs/ACCESS_REVIEW_RUNBOOK.md` — step-by-step certification process
- `docs/COMPLIANCE_FOLLOWUP_PROCESS.md` — compliance follow-up and escalation process

## Important
All users, systems, records, risks and controls are simulated. This project is for portfolio/learning purposes only and does not represent professional experience with Cameco systems.
