# Resume Bullets

**IT Access Governance & Compliance Lab** — Excel, Python, GRC

- Built a simulated IT governance and compliance workflow covering user access certification, privileged-access reviews, terminated-account reconciliation, compliance tracking, risk registers, control testing and exception management.
- Developed a Python analyzer to identify terminated-user access, stale privileged access and overdue certifications, producing structured findings and remediation reports from simulated access data.
- Created an Excel governance dashboard tracking access-review status, high-risk access, compliance deadlines, open exceptions and control effectiveness, supported by documented review and escalation procedures.

Use "simulated" or "educational" in interviews and project descriptions. Do not imply professional access to Cameco systems.
